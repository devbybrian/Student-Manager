# Student Manager

A console-based student management application built with C# and .NET.

This project was created to practice object-oriented programming, data management and the use of different collection types in C#.

## Overview

Student Manager allows student records to be created and managed through a command-line interface.

The project focuses on practicing C# fundamentals and understanding how different collection types can be used to store and organize application data.

## Current Features

- Add student records
- Update student grades
- Manage student information
- Check for duplicate student entries
- Track student-related operations
- Display and manage stored student data

## Technologies

- C#
- .NET
- Object-Oriented Programming

## C# Collections Used

The project uses several C# collection types for different purposes:

- `List<T>` — storing collections of objects
- `Dictionary<TKey, TValue>` — associating keys with student objects
- `HashSet<T>` — maintaining unique values
- `Queue<T>` — maintaining ordered pending operations
- `SortedList<TKey, TValue>` — organizing data using sorted keys
